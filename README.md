# MSc-Project-ZTE

MSc Physics project at King's College London. 

Investigating different approaches to fill the dead time gap in zero echo time magnetic resonance imaging (MRI)

## Required Packages: 
Numpy
Matplotlib
Pandas
Sigpy
JAX
Riesling
